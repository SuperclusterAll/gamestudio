# Autonomous Game Studio

기획 모델과 게임 코딩 모델로 HTML5 Canvas 게임을 제작하는 로컬 대시보드입니다.

## 현재 제작 방식

파이프라인은 총괄 감독(supervisor) 노드를 중심으로 한 허브 구조입니다.
각 단계는 끝나면 총괄 감독에게 돌아오고, 다음에 무엇을 할지는 총괄 감독만 결정합니다.

1. 장르와 플레이어 경험을 입력합니다. 빈 입력이면 기획 모델이 독자적으로 기획합니다.
2. 총괄 감독이 Deep Agents 서브에이전트와 프로덕션 계획을 정하고, 기획·기획서 단계가 이를 따릅니다.
3. 코드 모델이 핵심 규칙, 승패 조건, 상태 전환, 검증 기준을 구현 계약으로 작성합니다.
4. 사용자가 기획서와 구현 계약을 승인합니다.
5. 코드 모델이 원본 요청, 승인한 기획서, 구현 계약, 승인 메모에 따라 게임 파일을 작성합니다.
   스프라이트가 필요하면 코드 Agent가 직접 ComfyUI 이미지를 생성합니다.
6. JavaScript 문법 검사와 모델의 기획 일치 검증을 수행합니다. 규칙마다 코드 근거가 필요합니다.
7. 검증에 실패하면 총괄 감독이 남은 예산 안에서 다음 조치를 고릅니다.
   텍스트 수정 1회, 코드 Agent 재작업 2회, 아트 계획 재수립 1회가 예산이며,
   모두 소진하면 초안을 검토용으로만 배포하고 QA 미통과로 종료합니다.
8. 검증이 통과해야 index.html을 완성본으로 저장하고 완료로 표시합니다.

인증 오류, 기획 실패, 코드 미작성, 검증 실패를 고정 게임으로 대체하지 않습니다.
오프라인 고정 게임 생성은 대시보드와 CLI 제작 경로에서 사용할 수 없습니다.
기획 일치 검증은 모델의 소스 코드 검토이며, 자동 브라우저 플레이테스트를 의미하지 않습니다.

## 실행

PowerShell에서:

```powershell
cd C:\dev\autonomous-game-studio
.\.venv\Scripts\python.exe -m game_studio.server --port 8765
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 기존 서버가 실행 중이면 별도 포트를 지정할 수 있습니다.

## 모델 연결

로컬 AWS 프로필 또는 프로젝트 .env의 AWS 인증 설정을 사용합니다.
.env.example에는 실제 비밀 값을 넣지 않습니다. 인증 정보는 채팅이나 소스에 공유하지 마세요.
AWS 프로필, 역할, SSO 등 boto3의 인증 제공 경로를 확인합니다.
인증 설정 존재 여부와 선택한 Bedrock 모델에 대한 실제 접근 권한은 별개입니다.

대시보드에서 기획 모델과 게임 코딩·검증 모델을 각각 선택할 수 있습니다.
기본 모델 ID는 기존 구성의 Claude Sonnet 4.5 추론 프로필입니다.
코드 작성 응답은 최대 16,000 출력 토큰을 요청합니다. 선택 모델 및 계정에서 이 설정을 지원해야 합니다.
현재 환경에서 인증이 없으면 시작 요청은 503 오류와 설정 안내를 반환합니다.

CLI 예시:

```powershell
.\.venv\Scripts\python.exe -m game_studio.cli create --brief "방을 탐험하고 무작위 강화로 보스를 처치하는 로그라이크" --code-model-id global.anthropic.claude-sonnet-4-5-20250929-v1:0
```

## 산출물과 실행

각 실행은 C:\dev\games\<run-id>에 격리됩니다.

- draft.html: 작성/수정 중인 코드
- index.html: 검증을 통과한 게임
- production-manifest.json: 기획, 구현 계약, 검증 근거, 사용 모델
- assets/: 선택적 ComfyUI 이미지 및 아트 계획

게임 URL은 /games/<run-id>/ 입니다. /games/<run-id>는 후행 슬래시가 있는 주소로 이동합니다.
JS/CSS/이미지는 같은 게임 폴더 안에서 제공됩니다. 서버를 재시작해도 디스크의 게임은 열 수 있습니다.
실행 목록과 승인 대기는 메모리에 있으므로 서버 재시작 시 유지되지 않습니다.

## ComfyUI

COMFYUI_SERVER 기본값은 http://127.0.0.1:8188 입니다.
COMFYUI_WORKFLOW_PATH 기본값은 C:\dev\ComfyUI\text_to_image_z_image_turbo_nodes.json 입니다.
현재 모델 파일은 해당 워크플로를 따릅니다. GGUF로 자동 전환하지 않습니다.
이미지 생성 실패는 도구 결과에 기록하며, 코드 모델은 사용 가능한 이미지 목록을 확인합니다.

## 직접 제작한 로그라이크

C:\dev\games\ember-vault 는 현재 대화의 코딩 모델이 직접 작성한 독립 게임입니다.
이 게임은 Bedrock 파이프라인 실행 성공 사례로 간주하지 않습니다.
여섯 방, 세 종류의 일반 적, 무작위 강화, 회복/위험 경로, 회피와 사격, 2단계 보스전을 구현했습니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

테스트는 승인 경계, 인증 누락 처리, 미작성 코드/검증 실패 차단, 요구사항 근거 누락,
이미지 도구 호출 및 게임 파일/자산 라우팅을 검사합니다.
모델 응답을 대체하는 단위 테스트는 실제 Bedrock 호출 검증과 구분합니다.
