## 빠른 참조

**파이프라인 한 줄 요약**
참조 이미지 분석(선택) → 총괄 감독(범위 결정) → 기획 → 구현 계약 → **사람 승인** → 아트 계획 → 코드 Agent → QA 2단 → 패키징
체인이 아니라 **허브**다. 모든 워커가 감독에게 돌아오고, 엣지를 고르는 곳은 감독 하나뿐이다.

**완성 후에도 끝이 아니다 — 두 개의 피드백 루프**

```
게임 피드백   플레이 → 보완점 입력 → 기획·계약 유지한 채 코드 Agent부터 재개발
              (같은 폴더·같은 파일을 덮어쓰고, 이미지 시간 예산은 새로 받는다)
이미지 피드백  스프라이트 평가(좋음/별로) → ChromaDB → 다음 런의 아트 기획이 예시로 조회
              ("별로"로 찍힌 것만 재개발 때 다시 그린다 — 평가 안 한 것은 그대로 둔다)
```

이미지 쪽은 **그림이 아니라 프롬프트가 전이된다.** 같은 프롬프트로 생성해도 다른 그림이 나오므로
복제가 아니라 학습이고, 코퍼스가 전부 자기 산출물이라 저작권 문제가 없다
(자세히는 [ARCHITECTURE.md §8](ARCHITECTURE.md)의 "아트 메모리 — 결과로 배우는 RAG").

**두 엔진**
`html5`는 단일 `index.html`(외부 의존성 0), `godot`은 Godot 4 프로젝트 + `run.bat`.
기획 단계는 전부 공유하고, 코드·검증·패키징에서만 갈라진다.

**참조 이미지 (선택)**
런 시작 폼에 이미지를 올리면 **비전 호출 1회**로 맵 구조·플레이 흐름·적 배치·화풍·객체 목록을
뽑아낸다. 그 뒤로 흐르는 것은 **글**이다 — 기획·아트·코드는 전부 텍스트 모델이라 이미지를 들고
다니면 단계마다 비전 호출이 필요하고, 상태는 super-step마다 통째로 직렬화된다.

**핵심 원칙 넷**
1. 사람의 승인이 진짜 게이트다 (SQLite 체크포인트로 재시작을 견딤)
2. 판단이 필요한 곳에만 모델을 쓴다 (supervisor 8회 방문 = 모델 1회)
3. 검증은 게임을 못 돌게 하는 것만 막고, **만들 수 없게 된 것은 요구하지 않는다**
4. **강제는 스키마와 코드로, 부탁은 프롬프트로** — 모델이 조용히 넘길 수 있는 상한은 예산이 아니다

**실패를 숨기지 않는다**
Bedrock 없음 → 거부. Godot 없음 → 건너뜀 명시. QA 미통과 → 미해결 항목과 함께 배포.
폴백 게임을 만드는 코드 자체가 없다.

**저장 위치**
산출물은 `GAME_OUTPUT_DIR/<제목>_<엔진>_<런id>/`, 스튜디오 자신의 상태는 프로젝트의 `data/`
(체크포인트 DB + ChromaDB 아트 메모리 · git 무시 · 첫 실행 시 자동 생성).

## 자주 만지는 설정

```bash
CODE_AGENT_MODEL_CALLS=70   # 코드 Agent 호출 예산 — 폭주 루프 차단용 상한(실측 사용량 9~21회)
COMFYUI_CFG=1.0             # Z-Image Turbo가 증류된 조건. 올리면 느려지고 네거티브가 살아난다
COMFYUI_TIME_BUDGET_SECONDS=600  # 런당 이미지 생성 시간. 다 쓰면 Canvas 도형으로 넘어간다
COMFYUI_SPRITE_PIXELS=512   # 스프라이트 캔버스 상한 (배경만 1024)
MAX_REFERENCE_IMAGES=3      # 런 시작 시 올릴 수 있는 참조 이미지 수
MAX_RETHINK_CYCLES=2        # 가장 비싼 손잡이 (코드 Agent 루프 전체 + 재감사)
CODE_MAX_TOKENS=32000       # 한 턴 출력 상한 (게임 전문이 도구 인자로 나간다)
QA_REJECT_TOLERANCE=0.5     # 계약의 이 비율을 넘게 미충족해야 차단
DIRECTOR_TIMEOUT_SECONDS=0  # 총괄 감독 범위 결정 패스 (0이면 생략)
CHECKPOINT_RETENTION_DAYS=3 # 끝난 런의 체크포인트를 며칠 뒤 정리할지
BEDROCK_PRICING_MODE=ondemand  # ondemand(종량제) / provisioned(정액제·약정)
BEDROCK_PROMPT_CACHE_TTL=5m # off 로 끌 수 있음
STUDIO_DATA_DIR=            # 체크포인트·벡터 DB 위치 (기본: 프로젝트 data/)
```

전체 목록과 주석은 `.env`에 있다.
