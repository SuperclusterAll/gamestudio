# 잿불 금고 — Ember Vault

요청: 재미있고 스릴 있는 로그라이크. 이 버전은 현재 대화의 코딩 모델이 직접 작성한 게임이며, Bedrock 파이프라인 실행 결과가 아닙니다.

- 여섯 개 방을 순서대로 통과하고 마지막 수호자를 처치하면 승리합니다. 체력이 0이 되면 탐험이 끝납니다.
- WASD/방향키 이동, 마우스 조준, 클릭/Space 사격, Shift 회피. P로 일시정지합니다.
- 첫 방 이후 적의 구성이 실행 시드에 따라 바뀝니다. 추격병, 원거리 사수, 돌진병은 서로 다른 행동을 합니다.
- 전투를 마치면 무작위로 제시된 세 강화 중 하나를 선택합니다. 피해, 연사, 다중 탄환, 체력, 회피, 처치 회복이 실제 전투 수치를 바꿉니다.
- 다음 방을 선택할 때 위험 경로는 적이 늘고 클리어 보상으로 공격력 12%를 줍니다. 회복 경로는 체력 22를 회복합니다. 마지막 보스방에는 추가 적과 위험 보상이 없습니다.
- 수호자는 방사형 탄환과 지연 폭발을 사용하며, 체력이 절반 아래로 떨어지면 공격 주기가 짧아집니다.
- 새 탐험은 시드, 방, 체력, 강화, 점수를 초기화합니다. 기존 생성 게임의 코드를 재사용하지 않았습니다.

검증: JavaScript 문법 검사와 시뮬레이션 테스트(이동/회피/정지, 탄환 피해/사망, 방 진행/강화/승리/재시작, 시드 재현, 보스 공격).
